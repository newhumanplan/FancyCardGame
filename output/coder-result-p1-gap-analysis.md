## 三、差距清单 — 待开发功能 ❌

### 🔴 P0 — 核心玩法缺失（阻塞游戏可玩性）

#### P0-1: 24个MVP物品数据化
**策划**: 背包系统策划案 §八 MVP物品清单（24个）
**现状**: 仅18个 .tres 资源文件，且未使用（商店用随机生成）
**差距**: 
- 策划定义24个物品（Small12 + Medium8 + Large4），代码只有随机属性生成
- 物品需要从配置加载（JSON/.tres），不是运行时随机
- 策划定义了具体数值（如铁剑 15伤害 CD3s），代码用 `randi_range` 生成
- **物品效果类型缺失**: Burn/Freeze/Haste/Slow/Destroy 策划关键词未实现
**涉及文件**: item_data.gd, 新建 items_config.json, shop_ui.gd
**验收标准**: 
1. 24个物品数据完整配置
2. 商店从物品池随机抽取（不是随机生成属性）
3. 物品品质概率符合策划（Day1-3: 70/25/5/0）

#### P0-2: 触发链系统
**策划**: 物品触发机制策划案 §三 触发链
**现状**: 物品独立触发，无联动
**差距**:
- 相邻物品触发联动（如剑+毒药组合）
- 位置触发（最左/最右加成）
- 技能"连锁反应"（暴击时充能相邻物品1s）
**涉及文件**: battle_system.gd, item_effects.gd
**验收标准**:
1. 相邻武器触发时毒药也触发
2. 最左武器+10伤害，最右护盾+20护盾值

#### P0-3: 怪物扩展到10个
**策划**: 怪物系统策划案 §一（10个怪物）
**现状**: 仅3个（史莱姆/哥布林/食人魔）
**差距**:
- 缺少7个怪物：蝙蝠、骷髅兵、狼、蜘蛛、哥布林酋长(精英)、骷髅法师(精英)、史莱姆王(Boss)、亡灵骑士(Boss)
- 缺少怪物特殊技能：偷窃、闪避、连击、毒网、火球术、分裂、吞噬、冲锋、恐惧
- 怪物选择应按Tier分层（T1 Day1-3, T2 Day4-7, T3 Day8+）
**涉及文件**: battle_ui.gd _generate_random_monster, monster_data.gd
**验收标准**:
1. 10个怪物全部实现，带技能
2. Tier分层匹配策划

#### P0-4: 英雄物品池限制
**策划**: 英雄系统策划案 §四 专属物品池
**现状**: 无限制，所有英雄可用所有物品
**差距**:
- 战士禁用：长弓、魔法书
- 法师禁用：战斧、巨剑、塔盾
- 专属物品：战士(反击护符)、法师(火球术/冰霜新星/毒素云雾/智慧护符/魔力水晶)
**涉及文件**: hero_data.gd, shop_ui.gd
**验收标准**:
1. 战士商店不出现法师限制物品
2. 法师商店不出现战士限制物品

#### P0-5: 战利品系统
**策划**: 怪物系统策划案 §三 战利品
**现状**: 仅金币奖励
**差距**:
- 普通怪物：20-40%掉落物品
- 精英怪物：60-80%掉落物品 + 20-30%掉落技能
- Boss：100%史诗+物品 + 40-50%掉落技能
**涉及文件**: battle_ui.gd, game_manager.gd
**验收标准**:
1. 战斗胜利后可掉落物品到背包
2. 精英/Boss掉落概率正确

### 🟡 P1 — 重要功能（影响游戏深度）

#### P1-1: 英雄属性重构
**策划**: 英雄系统 §三 属性详解
**现状**: hero_data.gd 有 max_hp/crit_chance，缺 attack/defense
**差距**:
- 缺少 attack（攻击力）— 影响物品伤害计算
- 缺少 defense（防御力）— 影响受伤减免
- 伤害计算公式：`物品伤害 × (1 + ATK%)`、`受到伤害 × (1 - DEF%)`
**涉及文件**: hero_data.gd, battle_system.gd
**验收标准**: 
1. 攻击力影响物品伤害
2. 防御力减少受到伤害

#### P1-2: 技能系统扩展
**策划**: 技能系统策划案 §二（10个技能）
**现状**: 8个通用技能 + 2英雄各2被动
**差距**:
- 缺少触发类技能：开场爆发、反击姿态、连锁反应
- 缺少协同类技能：左侧强化、相邻支援
- 技能槽位系统：2-6槽（Day5/10+1）
- 技能获取：怪物掉落
**涉及文件**: skill_manager.gd, skill_data.gd, battle_system.gd
**验收标准**:
1. 至少实现触发类"开场爆发"和协同类"左侧强化"
2. 技能槽位随天数增长

#### P1-3: 商店刷新/锁定
**策划**: 商店系统 §一 刷新机制
**现状**: 每次进入自动刷新，无手动刷新
**差距**:
- 免费刷新1次/Day
- 付费刷新（2金币）
- 锁定功能（P1+）
**涉及文件**: shop_ui.gd
**验收标准**:
1. 每天可免费刷新1次
2. 付费刷新消耗2金币
3. 锁定物品不被刷新

#### P1-4: 物品出售
**策划**: 商店系统 §三 出售规则
**现状**: 无出售功能
**差距**:
- 出售价格 = 购买价 × 50%（稀有以上递减）
**涉及文件**: inventory_ui.gd 或 shop_ui.gd
**验收标准**: 物品可出售获得金币

#### P1-5: 合成系统重构
**现状**: shop_ui.gd 有"两个同稀有度合成更高稀有度"
**策划**: **无合成系统**。原版大巴扎是商店刷新轮转，不是合成
**差距**: 合成逻辑与策划不符，需要移除或重新设计
**涉及文件**: shop_ui.gd
**验收标准**: 移除合成逻辑（或确认为扩展功能）

## 五、建议执行顺序

**Phase 1（核心可玩）**: P0-1 → P0-4 → P0-3 → P0-5 → P0-2
**Phase 2（深度体验）**: P1-1 → P1-2 → P1-3 → P1-4 → P1-5
**Phase 3（打磨）**: P2 全部

**理由**：
1. P0-1（物品数据化）是所有后续功能的基础
2. P0-4（英雄物品池）改动小，快速交付
3. P0-3（怪物扩展）与 P0-5（战利品）配合
4. P0-2（触发链）最复杂，放最后
