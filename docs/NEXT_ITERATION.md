### 商店物品定价规则
```
基础价格 = 物品稀有度 * 100
- 普通 (Common): 100 金币
- 优秀 (Uncommon): 200 金币
- 稀有 (Rare): 400 金币
- 史诗 (Epic): 800 金币
- 传说 (Legendary): 1600 金币

出售价格 = 购买价格 * 30%
```
