# 《大巴扎》风格自走棋游戏 - 项目规划

## 一、项目概述

### 1.1 项目背景

《大巴扎》(The Bazaar) 是由 Richard Garfield（万智牌创始人）设计的多人英雄构筑 Roguelike 策略游戏，核心玩法：
- **类背包自走棋**：玩家在背包格子中放置物品/卡牌
- **英雄系统**：不同英雄有不同技能和玩法
- **物品构筑**：收集物品组合出各种流派
- **回合制对战**：与怪物和其他玩家对战

类似游戏参考：
- 《背包乱斗》(Backpack Hero) - 背包管理+自动战斗
- 《背包乱斗：福西法的宝藏》- 更成熟的背包自走棋

### 1.2 技术栈

- **游戏引擎**：Godot 4.x
- **美术工具**：本地 Stable Diffusion
- **文档协作**：飞书

---

## 二、核心模块清单

基于对《大巴扎》和《背包乱斗》的分析，游戏核心模块如下：

### 2.1 英雄系统
- 英雄选择界面
- 英雄属性（生命值、攻击力、防御等）
- 英雄特有技能
- 英雄专属物品池

### 2.2 物品系统
- 物品分类（武器、护甲、饰品、消耗品）
- 物品品质（普通、稀有、史诗、传说）
- 物品尺寸（大中小三格）
- 物品效果与组合

### 2.3 背包/棋盘系统
- 背包网格系统
- 物品摆放位置影响战斗力
- 物品合成与升级
- 存储空间管理

### 2.4 战斗系统
- 回合制自动战斗
- 战斗动画与特效
- 伤害计算
- 战斗日志

### 2.5 商店系统
- 物品购买与出售
- 刷新机制
- 议价系统
- 物品池管理

### 2.6 怪物/Boss系统
- 怪物种类与属性
- Boss战斗
- 怪物掉落

### 2.7 玩家对战系统
- 异步PVP（镜像对战）
- 匹配系统
- 天梯/排位

### 2.8 升级/经验系统
- 角色升级
- 技能树
- 天赋系统

### 2.9 事件系统
- 随机事件
- 奖励与惩罚事件

### 2.10 Roguelike系统
- 地图探索
- 随机生成
- 每次游戏体验不同

## 三、开发计划（分阶段）

### 阶段1：MVP（最小可行性产品）
**目标**：实现核心战斗循环

| 模块 | 描述 | 优先级 |
|------|------|--------|
| 英雄系统基础 | 创建1-2个英雄，基础属性和技能 | P0 |
| 物品系统基础 | 10-20种基础物品，3种品质 | P0 |
| 背包系统 | 基础网格，物品拖拽放置 | P0 |
| 战斗系统 | 自动战斗，伤害计算 | P0 |
| 怪物系统 | 5-10种怪物，Boss战斗 | P1 |
| 商店系统 | 基础购买，物品刷新 | P1 |

### 阶段2：游戏循环完善
**目标**：完成单局游戏体验

| 模块 | 描述 | 优先级 |
|------|------|--------|
| 地图系统 | 简单roguelike地图 | P0 |
| 事件系统 | 随机事件 | P1 |
| 经验系统 | 升级与技能树 | P1 |
| 物品合成 | 物品组合效果 | P2 |

### 阶段3：多人对战
**目标**：实现异步PVP

| 模块 | 描述 | 优先级 |
|------|------|--------|
| 玩家镜像 | 保存玩家阵容数据 | P0 |
| 对战匹配 | 随机匹配其他玩家 | P0 |
| 天梯系统 | 排位赛 | P2 |

### 阶段4：内容扩展
**目标**：丰富游戏内容

| 模块 | 描述 | 优先级 |
|------|------|--------|
| 更多英雄 | 3-6个英雄 | P1 |
| 更多物品 | 扩展物品库 | P1 |
| 皮肤系统 | 美术资产 | P2 |
