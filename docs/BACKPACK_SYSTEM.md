# 背包系统策划案

## 1. 系统概述

背包系统是《大巴扎》风格游戏的核心特色。玩家需要在有限的背包格子中合理摆放物品，物品的摆放位置会影响整体战斗力。

## 2. 背包结构

### 2.1 基础规格

- **背包大小**：6x6 网格（共36格）
- **可用区域**：玩家可以放置物品的区域
- **存储区**：暂时不使用的物品存放区域

### 2.2 物品放置规则

- 物品必须完整放置在背包网格内
- 物品不能重叠
- 物品可以随时重新排列

## 3. 位置影响机制

### 3.1 核心原理

物品在背包中的位置会影响其效果：
- **中心位置**：物品效果+10%
- **边缘位置**：物品效果正常
- **相邻同类物品**：触发组合效果

### 3.2 战斗位置

进入战斗时，背包中的物品会自动装备：
- 武器位置：攻击力加成
- 护甲位置：防御力加成
- 饰品位置：特殊效果

## 4. 物品操作

### 4.1 拖拽系统
- 长按物品可拖拽移动
- 拖拽时显示有效放置位置
- 释放后自动吸附到网格

### 4.2 快捷操作
- **出售**：将物品拖到商店图标
- **查看详情**：点击物品显示详情面板

## 5. UI设计

### 5.1 背包界面布局

```
+---------------------------+
|  英雄信息    |  背包网格    |
|  (左侧)      |  (中央)      |
|-------------|              |
|  物品详情    |  操作按钮    |
|  (底部)      |  (右侧)      |
+---------------------------+
```

### 5.2 视觉反馈

- 物品悬停：显示详细信息
- 有效放置：绿色高亮
- 无效放置：红色提示
- 组合效果触发：发光特效
