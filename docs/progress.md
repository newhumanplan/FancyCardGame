## 本次完成内容

### Phase 5: 商店系统

#### 1. 金币管理器 (`scripts/gold_manager.gd`)
- 自动加载单例 (Autoload)
- 金币数量管理
- 信号：gold_changed(amount)
- 方法：add_gold(), spend_gold(), can_afford()
- 初始金币：100

#### 2. 商店物品 (`resources/shop_item.gd`)
- 扩展 Item 类
- 添加价格属性 (price)
- 添加库存属性 (stock)
- 库存管理：-1 表示无限

#### 3. 商店系统 (`scripts/shop.gd`)
- 商店物品列表管理
- 购买逻辑：检查金币 → 扣款 → 添加到背包
- 出售逻辑：从背包移除 → 增加金币
- 商品刷新机制：每关卡刷新
- 自动生成商品列表

#### 4. 商店 UI (`scripts/shop_ui.gd`, `scenes/shop.tscn`)
- 商品网格显示
- 物品价格标签 (金色)
- 购买/出售按钮
- 金币实时显示
- 背包快速访问（用于出售）
- 出售价格显示 (绿色)

#### 5. 集成 (`scripts/main.gd`)
- 战斗胜利后自动打开商店
- 主界面添加商店按钮
- 主界面添加金币显示
- GoldManager 自动加载配置
