# 商店系统策划案

## 1. 系统概述

商店系统是玩家获取物品的主要途径之一。玩家可以使用游戏内货币购买物品，也可以出售不需要的物品。

## 2. 商店类型

### 2.1 主商店

- 出售各种基础物品
- 物品每日刷新
- 可以花费金币刷新

### 2.2 专业商店

- 出售特定类型物品
- 进阶功能，MVP后开发

## 3. 物品购买

### 3.1 购买流程

1. 与商店交互打开商店界面
2. 浏览可用物品
3. 选择物品并确认购买
4. 物品添加到背包/直接装备

### 3.2 物品价格

| 品质 | 价格范围 |
|------|----------|
| 普通 | 10-50 金币 |
| 稀有 | 50-200 金币 |
| 史诗 | 200-500 金币 |
| 传说 | 500+ 金币 |

## 4. 物品出售

### 4.1 出售价格

- 出售价格为购买价的30%
- 某些物品不可出售

### 4.2 批量出售

- 支持快速出售白色品质物品

## 5. 刷新机制

### 5.1 自动刷新

- 商店物品每日自动刷新

### 5.2 手动刷新

- 花费金币刷新
- 刷新费用：10金币，随刷新次数增加

## 6. 初始资金

- 玩家初始资金：100金币
