# 怪物系统策划案

## 1. 系统概述

怪物系统提供PVE内容，玩家通过击败怪物获得经验、金币和物品掉落。

## 2. 怪物分类

### 2.1 普通怪物

- 基础敌人
- 较弱的战斗能力
- 稳定掉落

### 2.2 精英怪物

- 较强的战斗能力
- 更好的掉落
- 较少出现

### 2.3 Boss

- 关卡结尾出现
- 强大的能力
- 丰厚奖励

## 4. 掉落系统

### 4.1 掉落概率

| 物品品质 | 掉落概率 |
|----------|----------|
| 普通 | 80% |
| 稀有 | 15% |
| 史诗 | 4% |
| 传说 | 1% |

### 4.2 掉落规则

- 击败怪物后随机掉落
- Boss保证掉落至少1件物品

## 5. 战斗机制

### 5.1 怪物行为

- 默认攻击玩家角色
- 某些怪物有特殊技能
- AI简单直观

### 5.2 难度曲线

- 随着关卡推进，怪物逐渐变强
- 每5关为一个难度阶段
