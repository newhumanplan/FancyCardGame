## 一、The Bazaar PvP 战斗界面（文字描述重构）

### 1.1 核心差异：Bazaar 不是传统卡牌对战

The Bazaar 是 **Hero Builder / Auto-Battler**，不是回合制卡牌对战。战斗是 **异步自动进行的**。

### 1.2 Bazaar 战斗界面布局（基于多源描述聚合）

```
┌──────────────────────────────────────────────────┐
│ [时钟] Day 3 Hour 5            ⭐ 7/10 Wins      │
├──────────────────────────────────────────────────┤
│                                                  │
│  ┌─────────┐                    ┌─────────┐       │
│  │ 对手英雄  │                    │ 己方英雄  │       │
│  │ 头像+名字 │                    │ 头像+名字 │       │
│  │ HP/护盾   │                    │ HP/护盾   │       │
│  └─────────┘                    └─────────┘       │
│                                                  │
│  ┌──────────────────────────────────────┐        │
│  │ 对手物品 Board（最多10格）             │        │
│  │ [物品1][物品2][__][物品4][__][物品6]  │ ← 全部可见│
│  │ 冷却遮罩丝滑覆盖                       │        │
│  └──────────────────────────────────────┘        │
│                                                  │
│  ┌──────────────────────────────────────┐        │
│  │ 己方物品 Board（Rug，最多10格）         │        │
│  │ [物品1][物品2][物品3][__][物品5][__]  │        │
│  │ 冷却遮罩丝滑覆盖                       │        │
│  └──────────────────────────────────────┘        │
│                                                  │
│  ┌──────────────────────────────────────┐        │
│  │ 宝箱（左下角）                         │        │
│  │ 临时buff/额外物品                       │        │
│  └──────────────────────────────────────┘        │
└──────────────────────────────────────────────────┘
```

### 1.3 关键布局规则

| 维度 | Bazaar 实际做法 |
|------|---------------|
| **整体布局** | 左右对称：对方在左/上，己方在右/下 |
| **英雄区域** | 英雄头像+名字+HP+护盾，显示在各自 board 上方 |
| **物品 Board** | "Rug"区域，初始4格，升级+2格，最多10格。物品按Small(1格)/Medium(2格)/Large(3格)占据空间 |
| **对方物品** | **全部可见**（不是隐藏的！）包括名称、属性、冷却 |
| **对方技能** | **全部可见** |
| **冷却显示** | 冷却遮罩丝滑覆盖，每个物品独立CD |
| **护盾** | HP条上方半透明 |
| **胜场** | 显示在左上角时钟上方 "7/10 Wins" |
| **物品交互** | 战斗中**不可操作**，纯观赏 |
| **伤害流向** | 直接对英雄HP |

## 二、FancyCardGame 当前 PvP UI 差异分析

### 2.1 布局差异对照表

| 维度 | Bazaar | FancyCardGame | 差距 |
|------|--------|--------------|------|
| 整体布局 | 左右对称 | 上下对称 | ⚠️ 方向不同 |
| 物品 Board | 10格，物品占1-3格不等 | 10格等宽，固定1格 | ⚠️ 缺少尺寸差异 |
| 对方物品 | **全部可见** | 背面卡牌（隐藏） | ❌ **重大差距** |
| 对方技能 | **全部可见** | 隐藏为 ❓ | ❌ **重大差距** |
| Board 交互 | 战斗中不可操作 | 旧 UI 中可点击选中 | ⚠️ 设计理念不同 |
| 胜场显示 | 时钟上方 "7/10 Wins" | 无 | ❌ 缺失 |
| 护盾条 | HP条上方半透明 | HP条上方浅蓝 | ✅ 一致 |
| 冷却遮罩 | 丝滑覆盖 | 丝滑覆盖 | ✅ 一致 |

### 2.2 差距严重程度排序

| 优先级 | 差距项 |
|--------|--------|
| **P0** | 对方物品应为**可见**（非背面隐藏） |
| **P0** | 对方技能应为**可见**（非❓隐藏） |
| **P0** | 胜场计数器缺失 |
| **P1** | 布局方向（上下→左右） |
| **P1** | 物品尺寸差异（S/M/L占1-3格） |
| **P2** | 英雄头像、宝箱区域、位置synergy |

## 三、重构建议

### Phase 1：P0 信息透明（1-2天）
1. 对方物品可见
1. 对方技能可见
1. 胜场计数器

### Phase 2：P1 布局对齐 + 物品尺寸（3-5天）
1. 左右对称布局
1. 物品尺寸 S/M/L
1. 物品拖放排列

### Phase 3：P2 完善体验
1. 英雄头像资源
1. 宝箱区域
1. 位置 synergy
