# Bazaar PvP 界面差异分析

> **2026-04-25 修订说明**：本文的有效结论是“The Bazaar 是自动战斗，不是回合制卡牌”。
> 文中提到的“手牌”仅用于指出旧 FCG UI 的错误方向，后续开发统一使用 board/items。

> **日期**：2026-04-15 | **调研方式**：多源搜索（Brave Search × 15 查询） | **可信度**：中等

## 一、The Bazaar PvP 战斗界面
### 1.1 核心差异：Bazaar 不是传统卡牌对战
The Bazaar 是 **Hero Builder / Auto-Battler**，战斗是 **异步自动进行的**。

### 1.2 关键布局规则

| 维度 | Bazaar 实际做法 |
|------|----------------|
| 整体布局 | 左右对称：对方在左/上，己方在右/下 |
| 英雄区域 | 英雄头像+名字+HP+护盾，显示在各自 board 上方 |
| 物品 Board | "Rug"区域，初始4格，升级+2格，最多10格。物品按Small(1格)/Medium(2格)/Large(3格) |
| 对方物品 | **全部可见**（包括名称、属性、冷却） |
| 对方技能 | **全部可见** |
| 冷却显示 | 冷却遮罩丝滑覆盖，每个物品独立CD |
| 护盾 | HP条上方半透明 |
| 胜场 | 显示在左上角时钟上方 "7/10 Wins" |
| 物品交互 | 战斗中**不可操作**，纯观赏 |
| 伤害流向 | 直接对英雄HP |

## 二、FancyCardGame 当前 PvP UI 差异分析

| 维度 | Bazaar | FancyCardGame | 差距 |
|------|--------|---------------|------|
| 整体布局 | 左右对称 | 上下对称 | ⚠️ 方向不同 |
| 物品 Board | 10格，物品占1-3格不等 | 10格等宽，固定1格 | ⚠️ 缺少尺寸差异 |
| 对方物品 | **全部可见** | 背面卡牌（隐藏） | ❌ **重大差距** |
| 对方技能 | **全部可见** | 隐藏为 ❓ | ❌ **重大差距** |
| Board 交互 | 战斗中不可操作 | 旧 UI 中可点击选中 | ⚠️ 设计理念不同 |
| 胜场显示 | 时钟上方 "7/10 Wins" | 无 | ❌ 缺失 |
| 护盾条 | HP条上方半透明 | HP条上方浅蓝 | ✅ 一致 |
| 冷却遮罩 | 丝滑覆盖 | 丝滑覆盖 | ✅ 一致 |

## 三、差距严重程度排序

| 优先级 | 差距项 |
|--------|--------|
| **P0** | 对方物品应为**可见**（非背面隐藏） |
| **P0** | 对方技能应为**可见**（非❓隐藏） |
| **P0** | 胜场计数器缺失 |
| **P1** | 布局方向（上下→左右） |
| **P1** | 物品尺寸差异（S/M/L占1-3格） |
| **P2** | 英雄头像、宝箱区域、位置synergy |
