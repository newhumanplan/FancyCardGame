# 英雄系统策划案

## 1. 系统概述

英雄系统是游戏的核心，每个英雄都有独特的属性、技能和物品池。玩家选择英雄后，将使用该英雄的专属物品进行战斗。

## 2. 英雄设计

### 2.1 基础属性

| 属性 | 说明 |
|------|------|
| 生命值 | 英雄的生命上限 |
| 攻击力 | 造成伤害的基础值 |
| 防御力 | 减免受到的伤害 |
| 速度 | 决定行动顺序 |
| 暴击率 | 暴击概率 |
| 暴击伤害 | 暴击时额外伤害 |

### 2.2 MVP阶段英雄设计

#### 英雄1：战士
- **定位**：近战物理输出
- **生命值**：100
- **攻击力**：15
- **防御力**：5
- **速度**：10
- **初始物品池**：剑、盾牌、护甲

#### 英雄2：法师
- **定位**：远程魔法输出
- **生命值**：80
- **攻击力**：20
- **防御力**：2
- **速度**：12
- **初始物品池**：法杖、魔法书、饰品

#### 英雄3：刺客
- **定位**：高爆发物理输出
- **生命值**：70
- **攻击力**：18
- **防御力**：1
- **速度**：15
- **初始物品池**：匕首、暗器、饰品

#### 英雄4：牧师
- **定位**：辅助治疗
- **生命值**：90
- **攻击力**：10
- **防御力**：4
- **速度**：8
- **初始物品池**：法杖、圣典、饰品

### 2.3 英雄技能

每个英雄有1-2个特有技能，例如：
- **战士 - 冲锋**：向敌人发起冲锋，造成额外伤害
- **法师 - 魔法护盾**：获得临时护盾

## 3. 物品池设计

每个英雄有专属物品池，物品分为以下类型：
- **武器**：增加攻击力
- **护甲**：增加防御力
- **饰品**：提供特殊效果
- **消耗品**：一次性使用

### 3.1 各英雄初始物品池

| 英雄 | 武器 | 护甲 | 饰品 | 消耗品 |
|------|------|------|------|--------|
| 战士 | 铁剑、钢剑 | 木盾、铁盾、皮甲 | 力量戒指 | 生命药水 |
| 法师 | 魔法杖、火之法杖 | - | 敏捷戒指、魔法书 | 魔法药水 |
| 刺客 | 匕首、暗器 | - | 暴击徽章、敏捷戒指 | 毒药 |
| 牧师 | 魔法杖 | 皮甲 | 生命项链 | 治疗药水 |

### 3.2 物品池解锁

- 初始：获得基础物品
- 等级2：解锁稀有品质物品
- 等级5：解锁史诗品质物品
- 等级8：解锁传说品质物品
