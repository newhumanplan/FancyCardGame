# 战斗系统策划案

## 1. 系统概述

战斗系统采用回合制自动战斗模式。玩家在准备阶段配置好物品和站位，战斗开始后自动进行。

## 2. 战斗流程

### 2.1 战斗阶段

1. **准备阶段**
   - 整理背包物品
   - 配置战斗阵容
   - 确认开始战斗

2. **匹配阶段**
   - 随机匹配对手（怪物或其他玩家）
   - 加载对手阵容数据

3. **战斗阶段**
   - 自动执行战斗
   - 显示战斗动画
   - 记录战斗日志

4. **结算阶段**
   - 显示战斗结果
   - 发放奖励
   - 记录战败原因

## 3. 伤害计算

### 3.1 基础公式

```
实际伤害 = (攻击力 - 防御力) × 位置修正 × 随机浮动
实际伤害 = max(1, 实际伤害)  // 最低造成1点伤害
随机浮动：0.9 ~ 1.1（±10%）
```

### 3.2 位置修正

| 物品位置 | 攻击力修正 | 防御力修正 |
|----------|------------|------------|
| 中心区域 | +10% | +10% |
| 边缘区域 | 0% | 0% |

### 3.3 暴击计算

```
暴击伤害 = 基础伤害 × (1 + 暴击伤害倍率)
暴击伤害默认 = 基础伤害 × 1.5
```

### 3.4 速度与行动顺序

- 速度越高，越先行动
- 速度相同时，随机决定顺序
- 速度差距超过20点，直接先手

### 3.5 能量系统

- 最大能量：10点
- 每回合恢复：3点
- 技能消耗：5-10点

## 4. 战斗动画

### 4.1 动画类型

| 动画 | 说明 | 持续时间 |
|------|------|----------|
| 攻击动画 | 角色进行攻击动作 | 0.5s |
| 受击动画 | 角色受击反应 | 0.3s |
| 暴击动画 | 暴击时特殊效果 | 0.8s |
| 技能动画 | 释放技能时显示 | 1.0s |
| 死亡动画 | 角色死亡效果 | 0.5s |

### 4.2 动画速度

- 默认战斗速度：1x
- 可切换：0.5x, 1x, 2x

## 5. 战斗回合时间轴

```
回合开始
  ↓
能量恢复（+3点）
  ↓
速度排序（决定行动顺序）
  ↓
角色1行动 → 攻击/技能 → 目标受伤
  ↓
角色2行动 → 攻击/技能 → 目标受伤
  ↓
...
角色N行动 → 攻击/技能 → 目标受伤
  ↓
检查胜负条件
  ↓
回合结束
```

### 5.1 胜负条件

| 条件 | 说明 |
|------|------|
| 胜利 | 敌方全部单位死亡 |
| 失败 | 己方全部单位死亡 |
| 平局 | 双方同时死亡（罕见） |

## 5. 战斗日志

### 5.1 日志内容

```
第1回合：
- 英雄攻击史莱姆，造成 15 点伤害
- 史莱姆攻击英雄，造成 5 点伤害
- 英雄击杀史莱姆！
```

### 5.2 日志功能

- 战斗后可查看详细日志
- 支持查看历史战斗记录

## 6. 战斗AI

### 6.1 怪物AI

- 默认攻击最前排目标
- 某些怪物有特殊行为模式

### 6.2 技能释放

- 满足条件时自动释放技能
- 技能有冷却时间
